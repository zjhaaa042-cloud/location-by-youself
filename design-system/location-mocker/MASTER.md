# Location Mocker 移动端设计系统

> 本文是前端视觉与交互的唯一基准。页面级规范位于 `pages/`；若页面文件与本文冲突，仅覆盖明确写出的部分。

**产品类型：** Android 工具类 App
**设计气质：** 专业、简洁、可信、克制
**技术基线：** Jetpack Compose + Material 3
**设计约束：** 不使用装饰性渐变、玻璃拟态、夸张大圆角或无意义动画。

## 1. 设计原则

1. 地图与坐标是内容主体，装饰元素不得争夺注意力。
2. 每个页面只有一个高强调主操作；停止、清空等危险操作与主操作分离。
3. 核心操作位于拇指易触区，并避开系统导航手势区域。
4. 状态使用“图标 + 文案 + 语义颜色”，不只依赖颜色。
5. 复杂参数渐进展示，默认界面服务于快速选点和启停模拟。
6. 优先使用 Material 3 原生控件与状态层，确保 TalkBack、键盘和点击反馈一致。

## 3. 字体层级

使用 Android 系统无衬线字体，不下载外部字体，避免首屏加载和中文字符回退不一致。

| 角色 | Material 3 | 建议 | 用途 |
|---|---|---|---|
| 页面标题 | `titleLarge` | 22sp / 600 | 顶栏标题 |
| 卡片标题 | `titleMedium` | 16sp / 600 | 状态与设置分组 |
| 正文 | `bodyMedium` | 14sp / 400 | 说明、地址 |
| 强调数值 | `titleSmall` + 等宽数字 | 14sp / 600 | 经纬度、速度 |
| 标签 | `labelLarge` | 14sp / 500 | 按钮、导航、状态标签 |
| 辅助文字 | `bodySmall` | 12sp / 400 | 提示和元信息，不低于 12sp |

正文默认允许换行。仅地图上的瞬时状态可使用单行省略，关键错误和权限说明不得截断。

## 4. 8 点间距体系

基础单位为 4dp，主要节奏使用 8dp 倍数。

| Token | 数值 | 用途 |
|---|---:|---|
| `space1` | 4dp | 图标内部微间距 |
| `space2` | 8dp | 同组元素间距 |
| `space3` | 12dp | 紧凑卡片内边距 |
| `space4` | 16dp | 页面水平边距、标准卡片内边距 |
| `space5` | 24dp | 分组间距 |
| `space6` | 32dp | 大区块分隔 |
| `space8` | 48dp | 空状态主间距、最小点击高度 |

手机页面水平边距 16dp；600dp 以上内容最大宽度 680dp 并居中；横屏可增至 24dp。

## 5. 圆角与阴影

| Token | 数值 | 用途 |
|---|---:|---|
| `radiusSmall` | 8dp | 状态标签、小按钮 |
| `radiusMedium` | 12dp | 输入框、普通卡片 |
| `radiusLarge` | 16dp | 重要卡片、底部控制栏 |
| `radiusSheet` | 24dp | 底部面板顶部圆角 |
| `elevation0` | 0dp | 页面背景、列表项 |
| `elevation1` | 1dp | 普通卡片 |
| `elevation2` | 3dp | 地图浮层、底部导航 |
| `elevation3` | 6dp | 弹窗、展开面板 |

阴影只用于层级分离，不用于装饰；深色主题优先使用 tonal elevation。

## 6. 图标

- 统一使用 Material Icons，导航同层级保持相同的填充/轮廓风格。
- 常规图标 24dp，紧凑状态图标 18dp，大空状态图标 40dp。
- 图标按钮交互区域至少 48×48dp。
- 纯装饰图标 `contentDescription = null`；无可见文字的操作必须提供明确中文描述。

## 7. 组件规范

### 按钮

- 主按钮：`Button`，高度至少 48dp，整屏只有一个高强调主按钮。
- 次按钮：`OutlinedButton` 或 `FilledTonalButton`。
- 文字按钮：用于关闭、取消和低风险辅助动作。
- 危险按钮：使用 error 语义色，执行前弹出确认。
- 加载时禁用重复点击，并在按钮内展示 `CircularProgressIndicator`。

### 输入框与搜索

- 使用可见标签，不以 placeholder 代替字段名称。
- 高度至少 56dp；错误显示在字段下方并说明恢复方式。
- 坐标输入使用十进制键盘语义；支持“纬度, 经度”和分隔空格。
- 搜索无结果不得显示空白页，应提供格式示例与返回地图选点入口。

### 卡片

- 普通卡片使用 `radiusMedium`、16dp 内边距、0–1dp elevation。
- 地图浮层使用不透明度不低于 96% 的 surface，保证地图复杂背景上的可读性。
- 避免把每行设置都做成独立卡片；使用分组容器和分隔线。

### 状态标签

- 未启动：中性图标 + “未启动”。
- 等待启动/已停止：主色容器 + “等待启动”或“已停止”。
- 启动中：进度指示 + “正在启动”，仅在有真实异步状态时使用。
- 运行中：成功色 + 运行图标 + “运行中”。
- 已暂停：警告色 + 暂停图标 + “已暂停”。
- 定位失败：错误色 + 错误图标 + “定位失败”，同时提供恢复动作。

### 弹窗

- 仅用于破坏性确认、无法在当前页面内恢复的错误和系统权限解释。
- 标题说明结果，正文说明原因，按钮文案使用具体动词。
- 取消/返回始终可用；弹窗不得承担顶层导航。

## 8. 页面规范

### 地图首页

- 顶部：搜索入口与权限提示，不并排堆叠多个浮层。
- 中部：地图，保留系统地图手势和定位按钮。
- 底部：当前/选中坐标摘要、状态、开始/暂停/停止；主按钮处于拇指区。
- 高级参数进入底部面板，不遮挡当前坐标和主操作。

### 地点/坐标搜索

- 顶栏提供返回。
- 默认展示最近/建议区域；本版本无业务数据时展示明确空状态。
- 坐标提交后返回地图并复用现有选点接口。
- 网络/搜索服务未接入时不得伪造地点结果。

### 收藏与历史

- 使用同屏分段切换，不增加超过 3 项的顶层导航。
- 空状态说明如何产生内容并提供返回地图 CTA。
- 列表项展示名称（若有）、经纬度、时间/类型（若数据源提供）和溢出菜单。

### 设置与权限

- 页面顺序：模拟默认值 → 跑道设置 → 权限与系统配置 → 关于与安全说明。
- 权限状态以清单展示，缺失项提供唯一明确入口。
- 不提供隐藏模拟定位、绕过检测或修改第三方安全策略的入口。

## 9. 导航与返回

- 底部导航：地图、保存、设置，图标与文字同时显示。
- 搜索和详情属于次级页面，返回到来源页面并保留状态。
- 返回优先级：关闭确认弹窗 → 收起底部面板 → 退出次级页面 → 系统默认返回。
- 横屏和大屏仍保持相同信息层级；可将控制区限制宽度并右侧/居中显示，不复制业务状态。

## 10. 动效与反馈

- 只使用 150–250ms 的淡入淡出或位置连续过渡。
- 不使用循环装饰动画、闪烁、弹跳庆祝或布局尺寸动画。
- 点击后 100ms 内出现 Material ripple/状态反馈。
- 地图和重组件不因无关 UI 状态变化被重建。

## 11. 无障碍与适配检查

- 正文对比度至少 4.5:1，大文字与 UI 图形至少 3:1。
- 点击区域至少 48dp，邻近目标间距至少 8dp。
- TalkBack 顺序与视觉顺序一致；选中、禁用、展开状态可被读出。
- 支持 320dp 小屏、常规手机、600dp+ 大屏、横屏和系统大字体。
- 固定底栏为内容预留安全区，不能遮挡列表末项或地图主操作。
- 亮/暗主题分别验证，不由单一主题推断另一主题。

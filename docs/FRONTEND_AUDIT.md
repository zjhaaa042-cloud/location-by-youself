# “模拟定位”前端审计与优化方案

## 1. 当前产品与技术边界

- 技术栈：Android、Kotlin、Jetpack Compose、Material 3、高德地图 SDK。
- 已有业务：定点模拟、路线模拟、操场识别、速度与播放方式控制、运行/暂停/停止、权限与系统设置引导。
- 已有持久化：速度、播放方式、当前路线点、操场信息、跑道方向。
- 当前不存在：地点关键词搜索接口、收藏数据源、历史数据源、独立设置路由、真实的“启动中”异步状态。
- 本轮约束：不修改定位逻辑、服务接口、领域数据结构，不实现绕过平台安全或第三方限制的能力。

## 2. 现有页面结构

当前应用只有一个 `MainScreen`：

1. 全屏高德地图。
2. 顶部权限与地图加载状态卡。
3. 底部模拟状态与播放控制坞。
4. 展开式二级控制面板：模式、速度、播放、操场识别、撤销与清空。

`MainScreen.kt` 超过 600 行，页面容器、展示组件、格式化逻辑和交互状态集中在同一文件。

## 3. 问题清单

### 信息架构

- 缺少顶层导航，地图、保存位置和设置无法形成清晰层级。
- 搜索、当前位置、选中坐标和运行状态没有稳定的信息顺序。
- 高级控制与主操作同时出现，首次使用认知负担偏高。
- 返回行为只依赖 Activity 默认退出，缺少页面内返回与弹层优先关闭规则。

### 视觉与设计系统

- 颜色虽已支持明暗主题，但仍定义在 Activity 内，无法被组件统一复用。
- 间距、圆角、图标尺寸、海拔/经纬度文本样式和 elevation 缺少集中 token。
- 状态主要依靠文字和局部颜色，缺少统一的图标、标签与语义映射。
- 卡片、控制坞和面板圆角接近，层级差异不够明确。

### 交互与状态

- 地图首页没有直接可见的搜索或坐标输入入口。
- 当前设备位置与选中/模拟位置没有独立的信息卡。
- 错误以状态文本为主，缺少“原因 + 恢复动作”的统一组件。
- 权限未授予、系统定位关闭、模拟位置应用未选择等场景没有分级说明。
- 搜索加载、无结果、网络异常、收藏空状态、历史空状态尚未建模。
- 领域层没有“启动中”状态，不能可靠展示真实启动进度。

### 响应式与无障碍

- 横向滚动虽然避免了部分溢出，但会降低操作可发现性。
- 622 行单文件增加了大字体与横屏适配的维护成本。
- 部分状态文本使用单行省略，系统字体放大时可能丢失关键信息。
- 需要系统化核对 48dp 点击区域、TalkBack 描述、选中/展开语义及颜色对比。

### 工程结构

- 页面、公共组件、主题和展示层格式化逻辑未拆分。
- 同类按钮、状态行、坐标文本存在重复组合。
- 地图重组件应保持稳定，避免仅因底部面板或导航切换发生不必要重建。

## 4. 优化方案

### 信息架构

- 顶层采用 3 个目的地：地图、保存、设置；底部导航最多 3 项并带文字标签。
- 搜索作为地图的次级页面，遵循系统返回；返回时保留地图和表单状态。
- 地图页固定顺序：搜索入口 → 地图 → 当前位置/选中坐标 → 状态与主控制。
- 高级参数使用底部面板渐进展示，主屏仅保留一个主操作。

### 组件体系

- `AppTheme`：亮/暗色板、字体、形状、系统栏颜色。
- `AppTopBar`、`AppBottomNavigation`：统一导航与返回。
- `LocationSearchBar`：地点/坐标入口和清晰标签。
- `CoordinateCard`：当前位置、选中点、模拟点统一展示。
- `SimulationStatusPanel`、`SimulationPrimaryAction`：状态和主操作。
- `PermissionBanner`：权限缺失与恢复动作。
- `StateMessage`：加载、空、错误、离线状态。
- `ConfirmDialog`：清空等破坏性操作确认。

### 页面策略

1. 公共组件：先落地 token、主题和状态组件。
2. 地图首页：核心操作位于屏幕下三分之一，地图保持最大可视区域。
3. 地点搜索：本轮提供经纬度解析与定位；关键词结果接口预留但不伪造。
4. 收藏与历史：展示规范空状态和本次已选坐标，不新增持久化结构。
5. 设置与权限：复用现有速度、播放、跑道方向和系统设置入口。

## 5. 验收标准

- `assembleDebug` 编译通过。
- 320dp 小屏、常规手机、600dp+ 大屏与横屏无不可达操作或意外横向溢出。
- 主要点击区域不小于 48dp，图标按钮均有可读描述。
- 正文文字在亮/暗主题均满足 WCAG AA 目标；状态不只依赖颜色。
- 地图、定位服务、ViewModel 公共 API 和领域数据结构保持不变。
- 每个页面具备适用的加载、空、错误或权限恢复状态。
